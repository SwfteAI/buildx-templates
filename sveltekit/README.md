# sveltekit

SvelteKit 2 scaffold with TypeScript and Tailwind CSS 3.

## Pre-baked

- `package.json` with `@sveltejs/kit@2`, `svelte@4`, `vite@5`, `tailwindcss@3`
- `svelte.config.js` with `@sveltejs/adapter-auto`
- `vite.config.ts` and `tsconfig.json`
- `tailwind.config.ts` + `postcss.config.js`
- `src/app.html`, `src/app.css`
- `src/routes/+layout.svelte`, `src/routes/+page.svelte`

## Commands

- `npm run dev` -> Vite dev server on port 5173
- `npm run build` -> production build
- `npm run preview` -> serve the production build
- `npm run check` -> svelte-check typecheck
